## 📌 项目定位

**ShadowStore** 是一个面向 Shadowrocket 的 **第三方开源模块聚合索引与检索平台**。

ShadowStore 致力于解决开源模块分散、检索困难、版本追踪不易的问题。平台坚持以下核心原则：
* **原始直链引用**：所有模块卡片均直接解析并指向 **原作者的官方开源仓库或原始资源直链**，不做任何代码篡改、二次打包或镜像托管。
* **零侵权与透明开放**：平台仅作为纯粹的元数据索引与导航工具，完整保留原作者署名、源仓库跳转链接与原版描述。
* **打造全景生态索引**：持续聚合开源社区中优质、实用、维护中的规则与模块，为用户提供一站式、毫秒级的检索与安装体验。

---

## ✨ 核心特性

* 🔗 **直链分发，尊重原创**：点击复制或安装均直接拉取原作者最新直链，确保用户始终获取官方原版更新，充分保障作者权益。
* 📦 **资源聚合，分类检索**：收录去广告、流媒体解锁检测、日常签到、实用插件等全场景模块，打造丰富的第三方资源库。
* 🔍 **智能别名与模糊搜索**：内置应用别名词典与多字段复合索引，输入中英文关键词或应用简称即可瞬时定位。
* 🚀 **一键唤醒安装**：深度集成 Shadowrocket URL Scheme 协议，手机端点击即可一键跳转导入客户端。
* 🎨 **现代交互体验**：自适应浅色与深色模式，支持流畅的移动端手势与响应式排版。
* 🔄 **自动化健康检查**：定时自检收录链接的有效性，自动标识失效或迁移模块，保持索引库新鲜度。
